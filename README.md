Take a popular anime picture from social networks and upload it to the app. Enter the character name and the series title, then click "Run". To see the 300K-view tweet about the app, search for "Kenjaku SFW" by Androidra (@AndroidraFr) on X/Twitter.

My ComfyUI App is based on 2 workflows: Qwen 3.5, which generates part of the prompt, and Anima1. I highly recommend testing those 2 workflows first to avoid troubleshooting issues.

Recommended parameters: LLM seed +1, batch size 4, turbo mode, number of runs 4, Auto size, max height 1280.

Warning: If you want to publish a picture without reviewing it first, we highly recommend disabling turbo mode to reduce the risk of inappropriate results.

Settings explained:

• Character name: You can enter several character names (e.g., Yor Forger left and Fiona Frost right).

• Auto size ON: Uses the dimensions of the uploaded picture; the maximum height is applied to keep the generation time low.

• Auto size OFF: The Width and Height parameters are used instead.

• Character Swap: Asks the LLM not to mention hair, skin color, height, or necklace.

• Force curvy woman: Asks the LLM to describe the character as a curvy woman.
